# Équipe — Site vitrine

Site statique en français présentant un concept de gestion des employés. Aucun compte ni stockage de données personnelles. Les chiffres et profils sont fictifs.

## Fichiers
- index.html : page de présentation
- style.css : styles adaptatifs
- vercel.json : publication statique depuis la racine

## Vercel
Importer ce dépôt, choisir Other, laisser les commandes de build et d’installation vides. Le dossier de sortie est la racine (.).
